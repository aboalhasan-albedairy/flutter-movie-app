## نبذة عن المشروع

**تطبيق سينما (Movie App)** هو مشروع عملي قيد البناء باستخدام **Flutter و Dart**، يهدف إلى تطبيق أساسيات بناء واجهات المستخدم، التنقل بين الصفحات، وإدارة الحالة بشكل عملي ضمن مسار التعلّم في الدورة.

> **حالة المشروع:** قيد العمل والتطوير المستمر، وسيتم إضافة لقطات الشاشة والميزات تدريجياً مع تقدم مراحل الإنجاز.
